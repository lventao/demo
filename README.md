## 📖 简介

本仓库是我学习 Git 时的练习记录，涵盖了日常开发中最常用的 Git 操作。

### 练习内容

| 文件 | 对应知识点 |
|:---|:---|
| `hello world.txt` | 初始化仓库、首次提交 |
| `new branch.txt` | 分支创建 (`git branch` / `git checkout -b`) |
| `second branch.txt` | 多分支并行开发 |
| `1` | Git 基本操作练习 |

### 涉及命令

```bash
# 分支操作
git init                    # 初始化仓库
git add .                   # 暂存文件
git commit -m "..."         # 提交更改
git branch <name>           # 创建分支
git checkout <name>         # 切换分支
git checkout -b <name>      # 创建并切换分支
git merge <name>            # 合并分支

# 查看状态
git status                  # 查看工作区状态
git log --oneline           # 查看提交历史
git diff                    # 查看文件差异
```
